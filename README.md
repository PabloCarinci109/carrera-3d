# 🏎️ TURBO RUSH 3D — Carreras

Un juego de carreras 3D en el navegador hecho con **Three.js**. Todo está en un
solo archivo `index.html`, sin dependencias ni build — solo ábrelo y juega.

## ▶️ Cómo jugar

**Opción 1 — Directo en el navegador**

Descarga `index.html` y ábrelo con doble clic.

**Opción 2 — Servidor local** (recomendado)

```bash
# con Python
python3 -m http.server 8000
# luego abre http://localhost:8000
```

**Opción 3 — Online**

Juégalo aquí: **https://pablocarinci109.github.io/carrera-3d/** *(activa GitHub Pages)*

## 🎮 Controles

| Tecla | Acción |
|-------|--------|
| `↑` / `W` | Acelerar |
| `↓` / `S` | Frenar |
| `← →` / `A D` | Girar |
| `Espacio` | Reiniciar |

## 🛠️ Tecnologías

- [Three.js](https://threejs.org/) — motor 3D en WebGL
- HTML + CSS + JavaScript puros (todo embebido)
